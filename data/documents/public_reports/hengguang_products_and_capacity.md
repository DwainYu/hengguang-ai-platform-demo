# 恒光股份主要产品、产能与基地分布

> **免责声明**：本文档为技术演示用途，产品目录与产能数据整理自公司 2024 年年度报告、
> 2025 年年度报告及官网公开产品介绍，产能利用率等指标随年度变化，不构成投资建议。

## 氯化工产品链主要产品

| 产品 | 基本性质 | 主要用途 |
|---|---|---|
| 氯酸钠 | 分子式 NaClO3，白色或微黄色等轴晶体，易溶于水、微溶于乙醇 | 净水、造纸、医疗、冶金、化工等行业 |
| 烧碱 | 包括 32% 与 50% 烧碱，分子式 NaOH，易溶于水形成碱性溶液，有潮解性 | 日化、造纸、印染、纺织、医药、冶金、化纤 |
| 液氯 | 分子式 Cl2，黄绿色液体，常压下汽化，有强烈刺激性与腐蚀性 | 纺织、造纸、净水、农药、洗涤剂、塑料、医药等含氯化合物 |
| 氯甲烷 | 分子式 CH3Cl，常温常压无色气体，微溶于水 | 有机硅原料，亦用作溶剂、冷冻剂、香料 |
| 盐酸 | 氯化氢（HCl）水溶液，无色透明液体，有强烈刺鼻气味 | 化学、冶金、食品、石油等行业 |
| 三氯化磷 | 分子式 PCl3，无色澄清发烟液体，易燃、有腐蚀性与剧毒性 | 有机农药、半导体掺杂剂、医药中间体、氯化剂与催化剂 |
| 三氯氧磷 | 分子式 POCl3，无色透明液体，有刺激性气味 | 医药、合成染料及塑料生产 |
| 三氯化铝 | 分子式 AlCl3，无色透明晶体或白色微带浅黄色结晶性粉末 | 冶炼、防腐、农药、絮凝及催化剂制造 |
| 氢气 | 分子式 H2，极易燃烧、无色无味且难溶于水 | 石油化工、电子、冶金、食品加工、浮法玻璃、双氧水原料 |
| 三氯氢硅 | 分子式 SiHCl3，无色液体，溶于苯、乙醚、庚烷等有机溶剂 | 多晶硅生产 |

## 硫化工产品链主要产品

| 产品 | 基本性质 | 主要用途 |
|---|---|---|
| 硫酸 | 分子式 H2SO4，无色无味油状液体，不挥发、易溶于水，有吸水性与腐蚀性 | 化肥、合成纤维、涂料、洗涤剂、石油、钢铁、医药等；发烟硫酸用于磺化剂、脱水剂、染料、石油精制 |
| 试剂硫酸 | 分子式 H2SO4，纯度更高 | 化学实验、化学分析、产品质量监测 |
| 精矿粉 / 铁精粉 | 分子式 Fe2O3 与 Fe3O4，硫铁矿焙烧后的褐红色混合物颗粒 | 炼铁、炼钢原料，主要用于冶金 |
| 蒸汽 | 分子式 H2O，分饱和蒸汽与过热蒸汽 | 加热、加湿及机器驱动动力 |
| 氨基磺酸 | 分子式 NH2SO3H，白色粉末，不挥发、无味无臭 | 甜味剂、清洗剂、漂白剂、燃料颜料、电镀添加剂 |
| 七水硫酸镁 | 分子式 MgSO4，白色细小斜状或斜柱状结晶，无臭味苦 | 制革、炸药、造纸、瓷器、肥料、医药 |
| 2-乙基蒽醌 | 分子式 C16H12O2，淡黄色片状晶体，溶于有机溶剂 | 制造双氧水、染料中间体、光固化树脂催化剂、光敏聚合引发剂 |
| 半胱胺盐酸盐 | 分子式 C2H8ClNS，白色或无色结晶，易溶于水和乙醇 | 医药中间体、农药中间体、饲料添加剂 |
| 焙烧渣 | 高硫渣脱硫后产物，内含铅、锌、银等元素 | 贵重金属提取 |

## 销售模式与收入结构（2024 年年度报告口径）

公司采用直销与经销相结合的销售模式，产品以买断式经销为主，统一使用产品购销合同或订单模板。
2024 年直销收入 749,128,329.94 元（占 60.67%），经销收入 485,729,626.26 元（占 39.33%）；
境内收入 1,114,462,790.76 元（占 90.25%），境外收入 120,395,165.44 元（占 9.75%，同比增长
47.78%）。分行业看，化工行业收入 1,225,363,507.63 元，占营业收入 99.23%。

## 连续生产与柔性生产特点

公司根据现代化工循环经济产业特点实行连续生产模式，在生产过程中及时调整产品结构，并不断优化
生产工艺、更新升级改造生产设备。氯、硫化工生产线配置具有较强"柔性生产"特征，能够根据市场
需求灵活调整不同产品产量，优化配置产业链上的化工产品种类，及时契合市场需求，规避下游行业
需求波动带来的业绩风险。
